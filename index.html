课表管理

支持手动录入与批量导入，实时推算当前节次、下一节课与剩余时长。可透过分享码快速同步至其他设备。

🎙️

录音与转写

课堂录音存档，支持本地转写并生成笔记。内置音频转码，可调整封装格式与码率，无需第三方工具。

🐟

全局桌宠

内置 106 组透明动画，支持拖拽、甩抛与贴边行为。Pro 模式下以悬浮窗形式常驻桌面，响应点击与语音反馈。

🤖

离线 AI

支持本地模型离线推理，问答、整理与总结均不依赖联网。同时开放自定义 API 接入。

🔒

账号可选

未注册即可使用全部功能；登录后课表与笔记可跨设备同步。数据默认存储于本地，可随时删除。
